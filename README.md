# Matematika

Complete edition of [Maths Explorer](https://github.com/ARHeritiana/Maths-explorer): the French lycée curriculum plus the Malagasy, international and university curricula.

This repository holds only the built site (GitHub Pages serves `main`). The source is the Maths-explorer repository; this edition is the same code with `FULL_EDITION = true` in `site/js/live-curriculum.js`. The French-only site is published at https://arheritiana.github.io/Maths-explorer/.
